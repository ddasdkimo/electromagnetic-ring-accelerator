# v2 試配塊（方案 B / Banked-Square 4）

對應設計文件：[docs/design-v2-alt.md](../../docs/design-v2-alt.md)　由 `stl` session 出圖（2026-07-28）。
原始參數化檔：`test_fit_v2.scad`。

## 印這三件

| 檔案 | 尺寸 / 擺法 | 驗什麼 |
|---|---|---|
| `test_v2_curve.stl` | 42×107×13，平躺 | **最重要**：直線 40 + 漸變 15（30 片）+ R85 弧 45°，球滾動順暢度與 banking 過渡有無頓挫 |
| `test_v2_bobbin.stl` | Ø22×30，立印 | 0.8mm 薄壁列印品質、Ø9.5 球通過性、繞線手感 |
| `test_v2_tunnel.stl` | 32×74×16，平躺 | 直線段 + bobbin 巢座 + 法蘭沉槽 + IR 孔（牆上 Ø3.5 橫穿 z8、x±13 直立管座），驗證進出隧道零落差 |

列印設定：PETG、0.2 層高。bobbin 用 **2 週線、關填充**（薄壁件），其餘照常。

## 關鍵幾何（CAD 已驗證，干涉 0.000）

- 球 Ø9.5，球心高 **8.218**（= r√2 − 平底半寬 + 底板 3）
- 直線段：對稱 45° V 槽，平底寬 3
- 彎道：整個槽輪廓繞球心旋轉 **20°**（外側面 65°、內側面 25°，槽夾角維持 90°），R=85
- 漸變段 15mm，只有 banking 角 0°→20° 線性變化，**球心高度全程不變**
- 隧道孔心 **9.068** = 球心 8.218 + 間隙/2 0.85
  （球是躺在孔底滾的，孔心與球心不同高——這點初版派工寫錯，由 stl 於出圖時抓出）
- 球心在直線段 / 漸變段中點 / 彎道 22.5° 三處皆恰相切

## 試印時要看什麼

1. 球放上去手推，**過渡段有沒有頓一下**——這是 v2 最核心的假設（banking 漸變不影響球心高度）
2. 彎道裡快速推球，看球是**貼在 65° 面上滾**還是爬到牆上
3. bobbin 0.8 壁有沒有破洞、Ø9.5 球通過是否順暢
4. IR Ø3.5 孔試插 3mm 對射管，兩側對光是否通
5. 球從開放槽進 bobbin 內孔，**有沒有可感的落差或撞擊聲**

結果回報後，stl 才出正式件。
