# v2 試配塊（方案 B / Banked-Square 4）

對應設計文件：[docs/design-v2-alt.md](../../docs/design-v2-alt.md)　由 `stl` session 出圖。
原始參數化檔：`test_fit_v2.scad`。

## 印這兩件

| 檔案 | 尺寸 / 擺法 | 驗什麼 |
|---|---|---|
| `test_v2_combo.stl` | 48×142×16，**平躺** | 一體連續軌道：彎道弧 45° → 漸變 15 → 直線段 60（含隧道巢座 + 法蘭淺槽 + IR 孔）。驗滾動順暢度、**banking 過渡有無頓挫**、進出隧道零落差、IR 對光 |
| `test_v2_bobbin.stl` | 22×17.6×30（D 形法蘭），**立印** | 0.8mm 薄壁列印品質、Ø9.5 球通過性、繞線手感 |

列印設定：PETG、0.2 層高。bobbin 用 **2 週線、關填充**（薄壁件），combo 照常。

> 為什麼是一體的 combo 而不是分開的軌道段＋隧道段：正式件本來就是一體列印無接縫，
> 用拼接來驗證過渡會引入正式件根本不存在的接縫誤差——而「過渡零落差」正是 v2 最核心的
> 驗證項，不該用會污染結果的方式去驗。（初版曾出分離的 curve + tunnel，已作廢移除。）

## 關鍵幾何（基準統一，CAD 驗證干涉 0.000）

- 球 Ø9.5，**球心高 11.218**（底板 6 + 5.218）
- 底面單一平面 z=0，底板全周 6mm，槽底基準面 z=6
- 直線段：對稱 45° V 槽，平底寬 3
- 彎道：整個槽輪廓繞球心旋轉 **20°**（外側面 65°、內側面 25°，槽夾角維持 90°），R=85
- 漸變段 15mm（30 片近似），只有 banking 角 0°→20° 線性變化，**球心高度全程不變**
- 隧道**孔心 12.068** = 球心 11.218 + 間隙/2 0.85（球躺孔底滾，孔心與球心不同高）
- D 形法蘭截平面 z=5.5（基準面下 0.5），沉槽底 5.2，**底膜 5.20mm**
- 球心 11.218 在彎道 / 漸變段 / 直線段三處皆恰相切

量測驗證（收錄時實測 STL 頂點）：關鍵 z 平面 0 / 5.200 / 5.802 / 6.000 / 6.828 / 8.790 / 11.000 / 12.000 / 13.236 / 16.000，
與設計值逐項對上；bobbin 截平距軸心 6.568，配孔心 12.068 得截平面 5.5 ✓ 兩件一致。

## 繞線提醒

法蘭半徑 11 只比線圈外徑（20.8）大 0.6mm/邊，對 0.5mm 線僅夠擋一層多；
D 形截平後正下方約 94° 沒有側擋。**繞線全程保持張力，繞完立刻用膠帶／熱縮套固定端頭**，不要指望法蘭擋線。
若線容易鬆脫，`test_fit_v2.scad` 的 `Z_CUT` 從 2.5 下修到 1.5 重出（無擋線角 94.2°→80.8°，底膜 5.2→4.2 仍充裕）。

## 試印時要看什麼

1. 球放上去手推，**過渡段有沒有頓一下**——這是 v2 最核心的假設（banking 漸變不改變球心高度）
2. 彎道裡快速推球，看球是**貼在 65° 面上滾**還是爬到外牆上
3. bobbin 0.8 壁有沒有破洞、Ø9.5 球通過是否順暢
4. IR Ø3.5 孔試插 3mm 對射管，兩側對光是否通
5. 球從開放槽進 bobbin 內孔，**有沒有可感的落差或撞擊聲**

結果回報後，stl 才出正式件。
