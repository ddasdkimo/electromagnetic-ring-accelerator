# em-accelerator — 電磁環形加速器（試配塊階段）

規格（ERA session 派工 2026-07-22）：鋼球 Ø12.7、中心圓 Ø240 一體印、4 線圈段、
bobbin ID14.5/壁0.8/C形/法蘭Ø26、IR Ø3 對射孔、PETG。

## 試配塊（先印這盤）

| 檔案 | 驗什麼 |
|---|---|
| `test_bobbin.stl`（26×26×24，立印） | 0.8 薄壁列印品質、球通過性、C 縫、法蘭出線孔、漆包線繞線手感 |
| `test_track.stl`（23×67×17 弧段，平躺） | 45° 雙軌滾動手感（球心 9.98 相切已 CAD 驗證）、外牆高度、IR Ø3 孔穿線與對光 |

## 已定的幾何核心（正式件沿用）

- U 槽剖面：底板 3、平底 4、45° 斜軌到 z8、內牆 z10、外牆 z17（高過球心抗離心）
- 球心高：開放段騎雙軌 = **9.98**；隧道段騎 bobbin 孔底 → **孔心 10.88** 時球心同高，
  過渡零落差（正式件的軌道↔bobbin 接合按此對位）
- IR 束高 z9（略低於球心，遮斷可靠）

試印重點：bobbin 用 0.2 層高、2 週線、關填充；track 弧段照常。
球放軌上手推應順滑無稜感；IR 孔試插 3mm 對射管。
