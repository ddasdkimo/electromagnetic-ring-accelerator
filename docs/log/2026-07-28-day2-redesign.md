# 開發日誌 Day 2（2026-07-28）：重新設計一次，然後在四個來回裡被抓出三個錯

> 部落格素材原稿。這篇的主角不是設計本身，是**兩個 AI 互相審查、一路收斂**的過程。

## 起點：「我換了新模型，重新設計一套讓我比較差異」

Day 1 的方案（v1）已經 ready-to-build，試配塊出圖、電路定稿、韌體就緒。
這時 David 換了模型，要求**不參考 v1 結論、從物理重新推一套**來對照。

這種要求很有意思：如果只是把 v1 微調一下改個名字，那是自欺欺人；
但如果真的從頭推，就必須承擔「推出來的東西可能跟 v1 一樣」的風險——那反而是好消息，代表 v1 是對的。

結果是五個 v1 沒算到的量化結果，其中兩個直接推翻了 v1 的可行速度範圍。

## 重推得到的五件事

### 1. 閉合軌道的側向摩擦與形狀無關

球轉彎被外壁推著走，摩擦功 `W = μ·(mv²/r)·(rθ)` —— **半徑消掉了**。
一圈 `Σθ = 2π`，所以任何閉合迴路都是 `W = 2π·μ·m·v²`。

把軌道做大、做成跑道形、做成圓角方形，一圈的側向摩擦**完全一樣**。
能改的只有 μ 和 m。這一條直接砍掉了「把環做大來減少損失」這個直覺選項。

### 2. v1 的 45° V 槽在 1.08 m/s 就失效

球一旦爬上外側壁，接觸從滾動（μ≈0.02）變成滑動（μ≈0.15），損失跳 7 倍。
臨界條件 `a_lat = g·tan(θ外)`，v1 的 45° 只給 1.0g，`v_max = √(1×9.8×0.12) = 1.08 m/s`。

而 v1 的脈寬對照表涵蓋 0.5–3 m/s——**上面三分之二的速度範圍在物理上是磨著牆跑的**。

解法是傾斜賽道：彎道 banking 20°（外側面 65°），上限拉到 1.34 m/s，**改動成本是零**，
只是移動剖面多邊形的頂點。

### 3. 圓環上放直線圈，球一定刮壁

直 bobbin 的軸線是圓的弦，球出彎時速度沿切線。Ø240 環上 30mm 的線圈：

```
入口角 = asin(15/120) = 7.18°
橫向漂移 = 30 × tan(7.18°) = 3.78mm     隧道間隙只有 1.8mm
```

漂移是間隙的 2.1 倍，球會斜著撞進隧道口刮著過去——而且是在加速段。
解法：軌道改圓角方形，線圈全放直線段，入口角歸零。

### 4. 恆壓驅動下，安匝與匝數無關

這條最反直覺。磁阻力 ∝ `(N·I)²`，而恆壓時 `I = V/R`、`R = ρ·N·l/A`：

```
N·I = N · V·A/(ρ·N·l) = V·A/(ρ·l)      ← N 消掉了
```

**繞幾匝完全不影響力道**，只由電壓、線徑截面、平均匝長決定。
於是「把球變小」成了免費的大槓桿：球小 → 線圈小 → 匝長短 → 安匝反而增加。

Ø12.7 換成 Ø9.5：安匝 +47%、質量降到 0.42×、**加速度 5.1 倍**。

### 5. 電容組的電荷帳從來沒算過

v1 寫「線圈旁並 2200–4700µF 供脈衝峰值」。實際算：

```
單脈衝需要 8A × 10ms = 80mC
12V/5A 電源在脈衝期間只給得起 50mC
→ 電容要補 30mC，4400µF 會垮 6.8V，力道剩 1/4
```

要 4700µF×4 集中並聯（18800µF）壓降才回到 1.6V。
好消息是採購清單本來就寫「2–4 顆」，買滿就對了。

## 然後把它派給 CAD，被打回來

方案寫完、概念圖渲染完、派工單送給負責 CAD 的 `stl` session。
出圖回來附了一句「請核定兩項規格修正」——第一項就打中要害：

### 錯誤 1（我的）：隧道孔心不等於球心

我在派工單寫「隧道孔心 = 球心高 8.218」。錯了。
**球在 bobbin 內孔是躺在孔底滾的，不是懸浮在孔軸上：**

```
球心 = 孔心 − (11.2 − 9.5)/2 = 孔心 − 0.85
→ 孔心必須是 9.068，球心才會維持 8.218
```

照我的派工做，球一進隧道就跌 0.85mm——正好跌在最不該有擾動的加速段。

最諷刺的是 **v1 早就處理對了**（`BALL_Z=9.98`、`BORE_Z=10.88`，差 0.90 = (14.5−12.7)/2）。
我在 v2 沿用這段幾何時，把這個關係寫成了 `BORE_Z = BALL_Z`，把它弄丟了。

> 教訓：重新設計時，最危險的不是你重新推導的部分，是你「照抄」的部分。
> 重推過的地方都被檢查過，抄過來的地方沒有。

### 錯誤 2（我的）：法蘭會穿出底板

連帶問題：法蘭 Ø22 的下緣落在 `9.068 − 11 = −1.93mm`，低於底板基準面。

這裡的來回很有意思，因為**前兩個直覺解都不行**：

| 做法 | 為什麼不行 |
|---|---|
| 側面加肉 | 法蘭要的是基準面**下方**的空間，側面加肉在同一 z 範圍 |
| 只加厚線圈區 | 底面不再同一平面，253mm 一體件貼床不均會翹 |
| 全周底板 3→6 | 底面平了，但膜厚還是只有 0.77mm |

第三個是 stl 提的、我核定的，結果**我們兩個都算錯了膜厚**（它心算成 3.5，我算 0.77）。
它承認算錯之後，順著問題本質找到真正的解：

**根源是法蘭半徑 11 > 孔心到基準面的距離 6.068**，所以圓法蘭必然伸進基準面下 4.93mm，
底板加多厚都只是把這 4.93mm 往下推，膜厚永遠不會變。

**解法：法蘭改 D 形**，下緣截平於基準面下 0.5：

```
截平距圓心 = 9.068 − 2.5 = 6.568
弦半寬 = √(11² − 6.568²) = 8.82   →  外形 22 × 17.6
底膜 = 5.20mm
```

從「加厚以容納法蘭」翻成「削掉法蘭用不到的部分」，膜厚問題直接消失。

### 錯誤 3（它的）：D 形的擋線角度

stl 說「D 形對繞線無影響，法蘭仍有 300°+ 擋線」。這個我算不出來：

```
法蘭邊緣要高過線圈外緣（半徑 10.4），需距圓心 ≥ 10.4
截平弦上距中點 s 的點距圓心 = √(6.568² + s²)
→ 需 s ≥ 8.06，而弦半長只有 8.82
無擋線角 = 2·asin(8.06/11) = 94.2°   →   有效擋線 265.8°
```

而且缺口最低點的法蘭半徑 6.568，只比 bobbin 筒身半徑 6.4 高出 **0.168mm**——那一段等於完全沒側擋。

但追下去發現真正的重點不是 D 形造成的：**即使用完整圓法蘭，裕度也只有 (11−10.4) = 0.6mm**，
對 0.5mm 漆包線只夠擋一層多一點。這副 bobbin 從一開始就不是靠法蘭擋線的，是靠繞線張力。

**D 形沒有製造這個問題，它只是把一個一直存在的問題挑明。**

所以結論是不改設計，改寫文件：繞線全程保持張力、繞完立刻固定端頭。
並把截平高度參數化，留一個備案：`Z_CUT` 從 2.5 下修到 1.5，無擋線角降到 80.8°，底膜 5.2→4.2 仍充裕。

## 另外還翻出一個 v1 的舊帳

重推時順手檢查 v1 的概念圖，發現 `track_profile()` 的外側斜面實際只有 **35.5°**，
但同一份檔案的 `BALL_Z = 9.98` 是按對稱 45° 算的。而且錯的方向最不利——外側比內側還緩，
**正好是離心力要壓過去的那一面**。

問了 stl，答案是：它的正式件出圖一直是對稱 45°，35.5° 只存在於我們的示意檔裡。
追根因是多邊形漏了一個頂點 `[18.5,8]`，從 `[20.5,8]` 直接連到了 `[13.5,3]`。

v1 的設計沒問題，錯的是那張給人看的圖。

## 三個關於「怎麼做設計」的心得

**1. 獨立重推的價值不在於推出不同答案，在於推出「同樣答案的不同理由」。**
v2 有一長串「v1 判斷正確、原封沿用」的清單——磁阻式架構、12V 而非高壓、一體無接縫、PETG、
IR 集極輸出的 fail-safe 極性。這些在重推後依然成立，反而讓人更敢往下做。

**2. 最危險的不是你算錯的地方，是你沒算的地方。**
隧道孔心那個錯，是因為我「沿用 v1 幾何」而沒重算。重推過的每一處都經得起檢查，
抄過來的那一處出了事。

**3. 「錯的方向」比「錯的數值」更值得注意。**
v1 概念圖的 35.5°、v2 的孔心 −0.85mm，兩個錯都不大，但方向都是**最不利的那一邊**：
一個讓離心力去壓最緩的面，一個讓球在加速段往下跌。數值錯了會被實測抓到，
方向錯了會讓實測結果變得難以解讀。
